PATH B: BUILD ANDROID APK
--------
1. Download Android Studio: https://developer.android.com/studio
2. Download Java: https://www.oracle.com/java/technologies/downloads/
3. Run: npm run build
4. Run: npx cap init
5. Run: npx cap add android
6. Run: npx cap sync android
7. Run: cd android && ./gradlew assembleDebug && cd ..
8. Install APK on phone (or use adb)
9. Share APK with friends!

Estimated time: 10-20 minutes (first time)

Or use pre-made scripts:
- Mac/Linux: bash APK_COMMANDS.sh
- Windows: APK_COMMANDS.bat

--------

--------

2. Open browser to http://localhost:5173
