📱 RAGE DEVIL APK - QUICK BUILD GUIDE

================================================================================
PREREQUISITES (One-Time Setup)
================================================================================

1. Download & Install Android Studio
   https://developer.android.com/studio

2. Install Java JDK 11+
   https://www.oracle.com/java/technologies/downloads/

3. Set Android SDK Path (after Android Studio install):
   Windows: setx ANDROID_HOME "%USERPROFILE%\AppData\Local\Android\Sdk"
   Mac/Linux: export ANDROID_HOME=$HOME/Android/Sdk

4. Verify Installation:
   java -version
   adb --version

================================================================================
QUICK BUILD (5 STEPS)
================================================================================

STEP 1: Build Web App
  npm run build

STEP 2: Setup Capacitor (First time only)
  npx cap init
  → App name: Rage Devil
  → App ID: com.ragedevil.game
  → Directory: .

STEP 3: Add Android Support (First time only)
  npx cap add android

STEP 4: Sync Files
  npx cap sync android

STEP 5: Build APK
  cd android
  ./gradlew assembleDebug
  cd ..

DONE! Your APK is at:
  android/app/build/outputs/apk/debug/app-debug.apk

================================================================================
INSTALL ON DEVICE
================================================================================

Method 1: USB Cable (Recommended)
  adb install android/app/build/outputs/apk/debug/app-debug.apk

Method 2: Manual
  1. Copy app-debug.apk to your phone
  2. Open file manager on phone
  3. Tap the APK
  4. Click Install

Method 3: Emulator
  Android Studio → Create Virtual Device → Run emulator
  adb install android/app/build/outputs/apk/debug/app-debug.apk

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "adb command not found"
Solution: Add to PATH: $ANDROID_HOME/platform-tools

Problem: "ANDROID_HOME not set"
Solution: 
  Windows: setx ANDROID_HOME "C:\Users\YourName\AppData\Local\Android\Sdk"
  Mac/Linux: export ANDROID_HOME=$HOME/Android/Sdk

Problem: "Gradle build failed"
Solution:
  cd android
  ./gradlew clean
  ./gradlew assembleDebug
  cd ..

Problem: "Build succeeded but APK not found"
Solution: Check: android/app/build/outputs/apk/debug/app-debug.apk
